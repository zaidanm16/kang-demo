# Kang Demo

Static, browser-only demo of the [Kang](https://github.com/zaidanm16/kang-deploy) dashboard: the real frontend with every API, Kong Admin API, and metrics call answered by an in-browser mock layer (MSW). No backend runs anywhere; nothing leaves your browser.

Live at: https://zaidanm16.github.io/kang-demo/

The demo is built from the `kang-frontend` repository by this repository's workflow; the mock dataset lives in `frontend/demo/`. Kang is closed source — the frontend repository is private, but its published demo build is public.

See the [documentation](https://zaidanm16.github.io/kang-deploy/) for installation and usage of the real application.
